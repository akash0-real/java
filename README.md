# ☕ Java Learning Journey

    Welcome to my comprehensive Java learning repository! This is a curated collection of programs, exercises, and projects that document my journey from Java fundamentals to advanced concepts. Each line of code represents a step forward in mastering one of the most powerful programming languages in the world.
    

---

## 📚 What's Inside

    This repository is organized into focused sections covering the full spectrum of Java development:
    
    Core Concepts -> 
    - Object-Oriented Programming (OOP) — Classes, objects, inheritance, polymorphism, abstraction, and encapsulation principles
    - Arrays — Operations, searching algorithms, sorting techniques, and data manipulation
    - Strings — Text processing, manipulation algorithms, and utility functions
    - Loops & Conditionals — Logic building blocks and problem-solving patterns
    - Methods — Creating reusable, modular code with proper design patterns
    
    Data Structures & Collections ->
    - Collections Framework — ArrayList, LinkedList, HashMap, HashSet implementations
    -Aggregation — Working with complex object relationships
    -Streams API — Functional operations like filter, map, reduce, and collectors
    
    Advanced Topics ->
    - File I/O — Reading, writing, and managing files with RandomAccessFile and buffers
    - Lambda Expressions — Functional programming paradigms and modern Java syntax
    - Networking — Client-server applications and socket programming
    - Threads — How to create and use threads and multithreading 
    - Record Classes — Immutable data carriers (Java 14+)
    
    Real-World Projects ->
    - Mini Applications — Inventory systems, Library system, many more
    - Practice Implementations — Hands-on solutions to common programming challenges

## 📖 How to Use This Repository

In terminal ->
1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/java.git
   cd java
   ```

2. **Navigate to any topic folder**
   ```bash
   cd OOP
   ```

3. **Compile and run any Java file**
   ```bash
   javac FileName.java
   java FileName
   ```

4. **Explore, learn, and experiment!**
